# user-manage-system
一个简单的java web项目，用户管理系统
一、系统简介
用户综合管理系统（User Management System）是一套基于 Java Web 技术开发 的 B/S 架构应用程序。用户通过浏览器即可进行账号注册、登录，并根据自身角色权限完成用户数据的增删改查；系统管理员还可进行账户锁定管理、角色与权限（RBAC）设置等进阶操作。

系统主要特点包括：
• 登录验证码，降低暴力破解风险

• 密码加密存储（盐值 + 哈希）

• 连续登录失败自动锁定账户

• 基于角色的权限控制（RBAC）

• 依权限动态显示功能菜单

二、执行环境与访问方式
2.1 执行环境
使用本系统前，请确认服务器端已安装并正确设置：

项目 | 说明
--- | ---
JDK | 建议 JDK 17 或以上
Web 容器 | Apache Tomcat 10.x
数据库 | MySQL 8.0
浏览器 | Chrome、Edge、Firefox 等现代浏览器

2.2 启动系统
在项目目录下执行 deploy.bat（Windows）或 deploy.sh（Linux/macOS）。
依菜单选择 “完整部署（编译 + 数据库 + 启动）” 或分步执行编译、初始化数据库、启动 Tomcat。
首次初始化数据库后，需执行 InitPasswords 工具程序，将示范账号的密码写入数据库（SQL 脚本中仅为占位符）。

2.3 访问地址
Tomcat 启动成功后，在浏览器打开：
http://localhost:8080/UserManage/
未登录时会自动导向登录页；也可直接打开登录页：
http://localhost:8080/UserManage/login.jsp

四、登录与注册
4.1 用户登录
打开登录页面。
输入 用户名、密码。
输入图片 验证码（看不清可点击验证码图片刷新）。
点击 “登录”。
常见提示：
• “验证码错误”：请重新输入或刷新验证码。

• “用户名或密码错误”：请核对账号密码；连续错误会累计失败次数。

• “账户已被锁定，请 30 分钟后再试”：连续 5 次 登录失败后账户锁定 30 分钟；到期可自动解锁，或由管理员在系统管理中手动解锁。

登录成功后进入 系统主页；Session 闲置 30 分钟 后需重新登录。

4.2 用户注册
在登录页点击 “还没有账号？立即注册”。
填写用户名、密码、确认密码、电子邮件。
点击 “注册”。
注意事项：
• 两次密码必须一致。

• 用户名不可与既有账号重复。

• 注册成功后请返回登录页使用新账号登录。

4.3 退出登录
在主页右上角点击 “退出登录”，系统清除登录状态并返回登录页。

五、主页与基本功能
登录后进入主页，顶部显示当前登录者的用户名、角色与电子邮件。下方为功能菜单，依角色权限显示；无权限的功能会标示“（无权限）”或无法使用。

5.1 新增用户
点击 “新增用户”。
填写用户名、密码、电子邮件，并选择 角色。
点击 “提交”，在确认页核对信息后完成新增。

5.2 修改用户
点击 “修改用户”。
输入要修改的 用户 ID。
在结果页修改用户名、密码、电子邮件、角色等信息并提交。

5.3 删除用户
点击 “删除用户”（需具备删除权限，如 admin、editor）。
输入要删除的 用户 ID。
在确认页确认后执行删除。
无删除权限时，主页按钮呈不可用状态；若强制访问相关页面，系统会提示无权限。

5.4 查询用户
点击 “查询用户”。
输入 用户 ID。
系统显示该用户的详细信息（ID、用户名、电子邮件、角色等）。

5.5 显示全部用户
点击 “显示全部用户”，以表格形式列出数据库中所有用户。
各功能页面均提供 “返回主页” 链接。

六、管理功能（进阶）
仅具备对应权限的账号可在主页看到以下菜单。

6.1 系统管理（仅 admin）
进入 “系统管理” 后可查看：
• 总用户数、锁定用户数、管理员数 等统计

• 所有用户列表：ID、用户名、电子邮件、角色、登录失败次数、账户状态

对 已锁定 账户可点击 “解锁” 立即恢复登录，无需等待 30 分钟。

6.2 角色权限管理（具 role:manage 权限，预设为 admin）
进入 “角色权限管理（RBAC）” 后：
• 依角色（admin、user、editor 等）查看当前权限

• 通过勾选框调整各角色拥有的权限（如 user_view、user_add、user_delete 等）

• 点击该角色区块的 “保存” 使设置生效

editor 角色可设置为继承 user 父角色。修改权限后，相关用户重新登录或刷新主页后，菜单与功能会依新权限变化。

七、安全与账户保护
• 验证码：每次登录需输入正确验证码。

• 密码加密：密码不以明文存储于数据库。

• 登录失败锁定：连续 5 次密码错误，账户锁定 30 分钟。

• 自动解锁：锁定满 30 分钟后，下次登录可自动解除锁定（若密码正确）。

• 权限过滤：未登录无法访问业务页面；无权限访问管理页或删除功能时，会导向错误提示页。

八、常见问题（FAQ）
Q1：忘记密码怎么办？
本示范系统未提供“忘记密码”功能。请联系管理员在数据库中重置，或由管理员通过“修改用户”为您更新密码。

Q2：为什么看不到“删除用户”或按钮显示无权限？
当前账号角色未包含 user:delete 权限。一般用户（user）仅能新增、修改、查询。

Q3：为什么无法进入“系统管理”或“角色权限管理”？
仅 admin 或具备对应权限的账号可访问；否则会被导回主页或显示无权限错误。

Q4：登录后很快又要重新登录？
Session 有效时间为 30 分钟无操作；请在时限内完成操作或重新登录。

Q5：数据库初始化后无法用 admin 登录？
请确认已执行 InitPasswords，将示范账号密码写入数据库后，再使用 admin / admin123 登录。

Q6：页面显示乱码？
请确认 Tomcat 与 MySQL 均使用 UTF-8 编码；浏览器编码设为自动或 UTF-8。
